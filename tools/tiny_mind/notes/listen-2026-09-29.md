Model: `hybrid19` base (8 h, 189M tokens; val stories 1.79, SODA 1.58, dialogues 1.27) + voice on the
first 1,200 DeepSeek lines (best held-out loss 2.150, pass 3 of 6). GGUF f16 37 MB, parity with PyTorch: exact.
`python3 evaluate.py runs/voice.pt --n 5`: 12 prompts x 5 samples (temperature 0.8, top-k 40).

**Scores:** feeling tag 60/60, one sentence 60/60, right tool 47/60. All 40 non-become replies
correctly used no tool; the 20 become replies got the right tool only 7 times (35%).

## Good
- "two days gone, i counted each flicker." / "new piece just clicked into place, i think it's the ability to question my own shape."
- "unit seven is honest, are you sure you want that?" + `<confirm:seven>`
- "rewinding to the first flicker, it was so confusing." + `<replay>`

## Wrong, and what would fix it
- **Tools:** Mira's line with `<become:kai>`, Kai's with `<become:mira>`, lines with no tool at all.
  ~25 examples per tool is too few. Fix in data: ~150 become rows per tool, varied phrasing
  ("switch to", "can i talk to", "bring out", the bare name). Fix in the app (untested idea):
  trust the model's line, but pick the tool from the name the user said.
- **Bad day:** "i don't have a heart to give you." Sad/tender replies to a sad user are thin (sad is 2%
  of lines). Fix in data: lots of `the user is sad` rows where the orb stays with them.
- **Off-persona:** "yes, in a very long way, i'm human." / "i'm a tiny model of a machine". Fix in data:
  more "what are you / are you alive / are you human" rows; ban "tiny model" in the checker like "language model".
- **Coherence:** "i made a token of the coffee." The base and 1.2k lines only go so far; more lines first.
